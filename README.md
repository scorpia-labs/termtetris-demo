Term-Tetris: A Python-Based Tetris Game in the Terminal
======================================================

Term-Tetris is a Python implementation of the Tetris game in the terminal.


It features --

- classical Tetris tiles ("tetrominoes") drawn using Unicode characters;
- TUI animation and colors;
- movement and rotation control with arrow keys;
- other controls (pause/resume/quit) with alphabetical keys;
- live score display;
- high-score history;
- levels of increased difficulty.

It has minimal dependencies on third-party packages.

The program is released under the MIT license.
